# PR Self-Review Checklist

- [ ] **Focused Task:** Does this PR solve exactly one clear task without unrelated changes?
- [ ] **Naming Conventions:** Are variable, class, and method names clear and meaningful?
- [ ] **Formatting & Cleanliness:** Is the code properly indented? Are all temporary debug echoes or comments removed?
- [ ] **No Code Duplication:** Did I avoid copying and pasting identical logic?
- [ ] **Edge Cases Covered:** Did I handle potential issues like empty arrays, null values, or division by zero?
- [ ] **Manual Testing:** Did I run the code in the terminal to confirm the output is correct and dynamic?
